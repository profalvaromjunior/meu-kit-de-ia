# Template: O Segredo de um Bom Pedido à IA

A estrutura das Aulas para qualquer pedido: contexto, instrução, objetivo e formato.

## Modelo

Copie pelo botão no canto do bloco e troque cada pergunta entre colchetes pela sua resposta.

```text
CONTEXTO
[O que a IA precisa saber para entender a situação?]

INSTRUÇÃO
[O que você quer que a IA faça?]

OBJETIVO
[Por que você precisa disso? O que deve acontecer depois?]

FORMATO
[Como a resposta deve ser entregue?]
```

## Teste do Estagiário

Se você entregasse esse pedido para uma pessoa nova no time, ela teria contexto suficiente para executar sem precisar adivinhar?

Se a resposta for "não", melhore o pedido.
